## 🛠️ How It Works (In Plain English)

When you run a 3D scene, your computer needs to figure out where every object is, how light bounces off surfaces, and what colors each pixel should be. That's a lot of math happening in real-time.

node-webgl sends all those calculations directly to your graphics card — the same powerful processor that makes video games look great. Instead of going through a web browser (which adds extra steps and slows things down), it communicates directly with your hardware. The result? Faster rendering, smoother animations, and richer detail.

The "headless" part means node-webgl doesn't need to open a window or show anything on screen. It does all the work invisibly in the background. This is incredibly useful for running 3D tasks automatically — like generating images, processing 3D models, or powering visualization tools.
